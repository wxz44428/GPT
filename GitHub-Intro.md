# A Basic Introduction to GitHub

## What GitHub is
GitHub is a website and cloud service for storing and sharing **Git repositories**. Git keeps the history of your files on your computer. GitHub keeps a copy online, so you can back it up, reach it from anywhere, and work on it with other people.

## A short history
- **2008:** Tom Preston-Werner, Chris Wanstrath, PJ Hyett, and Scott Chacon launched GitHub to make sharing Git projects easier.
- **2010s:** GitHub became the main home of open-source software, hosting projects from individuals and big companies alike.
- **2018:** Microsoft bought GitHub for $7.5 billion. GitHub still runs as its own platform.
- **2019:** Unlimited free private repositories were opened up to everyone.
- **2021 onward:** GitHub added AI tools, starting with GitHub Copilot, which suggests code as you type.

## What you can do on GitHub
- **Repositories:** store projects and documents, public or private.
- **Version history:** see every change and go back to older versions.
- **Issues:** keep to-do lists, track bugs, and hold discussions.
- **Pull requests:** propose changes and review them before they're merged.
- **GitHub Pages:** publish a simple website straight from a repository.
- **Actions:** run automatic tasks, such as checks or builds, when files change.

## Git vs. GitHub
**Git** is the tool that tracks changes. **GitHub** is one online service that hosts Git repositories. Others include GitLab and Bitbucket.

## Cost
The free plan includes unlimited public and private repositories. Paid plans add team features and extra storage. Keep single files under 100 MB, and keep each repository reasonably small (ideally under about 1 GB).
